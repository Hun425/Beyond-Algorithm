## [Smallest Palindromic Rearrangement I](https://leetcode.com/problems/smallest-palindromic-rearrangement-i/)

### 접근 방법

팰린드롬은 대칭되는 문자열을 뜻하는 말이다.
어떠한 문자열이 팰린드롬이라고 했을 때, 문자열의 앞 절반이 특정되면 나머지 절반이 정해진다는 특성이 있다.
이 점을 이용해 앞 절반의 문자열을 먼저 사전순으로 가장 으뜸이 되는 것으로 결정해주면 된다.

### 코드

```kotlin
class Solution {
    fun smallestPalindrome(s: String): String {
        val letterMap = mutableMapOf<Char, Int>()

        s.forEach { letter ->
            letterMap[letter] = letterMap.getOrDefault(letter, 0) + 1
        }

        val letterOfOddCount = letterMap.entries.singleOrNull { (it.value and 1) == 1 }?.key

        val result = letterMap.entries.sortedBy { it.key }.joinToString(separator = "") { (letter, count) ->
            letter.toString().repeat(count / 2)
        }.let {
            it + (letterOfOddCount ?: "") + it.reversed()
        }

        return result
    }
}
```

### 복잡도

- 시간복잡도: $O(N)$
- 공간복잡도: $O(N)$
