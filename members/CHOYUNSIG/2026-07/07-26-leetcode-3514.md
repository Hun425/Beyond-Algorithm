## [Number of Unique XOR Triplets II](https://leetcode.com/problems/number-of-unique-xor-triplets-ii/)

### 접근 방법

문제에 나온 대로 모든 삼중 XOR 값을 구해 개수를 세면 된다.

하지만 그냥 3중 반복문으로 구현하면 $O(n ^ 3)$의 시간복잡도가 소요되므로, $n \leq 1500$  범위에서 시간초과를 받을 수 있다.

$n$을 이진수로 표현했을 때 $a$글자였다면, $n$보다 작거나 같은 수 두개를 XOR 연산한 값은 무조건 $2 ^ a$보다 작으므로, 문제에 나온 `nums` 배열의 모든 원소를 아무리 XOR 연산을 해도 $2048(= 2 ^ {11})$보다 큰 수를 만들 수 없다. 따라서 모든 삼중 XOR 값을 구할 때, 모든 이중 XOR 값에서 XOR 연산을 한 번 더 하는 방식으로 구하면 연산할 숫자의 범위가 고정된 채로 연산을 하게 되므로 시간복잡도를 줄일 수 있다.

### 코드

```kotlin
class Solution {
    fun uniqueXorTriplets(nums: IntArray): Int {
        var xorSet = nums.toSet()

        repeat(2) {
            val nextXorSet = mutableSetOf<Int>()

            for (i in xorSet) {
                for (j in nums) {
                    nextXorSet.add(i xor j)
                }
            }

            xorSet = nextXorSet
        }

        return xorSet.size
    }
}
```

### 복잡도

- 시간복잡도: $O(n ^ 2)$
- 공간복잡도: $O(n)$
