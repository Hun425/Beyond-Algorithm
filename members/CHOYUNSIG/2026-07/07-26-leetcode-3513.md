## [Number of Unique XOR Triplets I](https://leetcode.com/problems/number-of-unique-xor-triplets-i/)

### 접근 방법

1부터 $n$까지의 수 중 중복을 허용해 아무거나 3개를 가지고 XOR 연산을 3번 실행해서 나올 수 있는 값의 개수를 반환하는 문제이다.

이 문제는 수학적 증명을 수반하는데, 바로 다음 사실이 증명 가능하다는 것이다.

> $n$을 이진수로 나타내었을 때 $a$글자로 표현된다면, 1부터 $n$까지의 수를 중복을 허용해 아무거나 3개 골라 XOR을 했을 때, $2^a$보다 작은 모든 자연수(0 포함)를 표현할 수 있다.

#### 증명

$n$을 이진수로 나타내었을 때 $a$글자였다고 해보자.

1. 1부터 $n$까지의 수를 얻기

우선 다음은 자명하다.

> $x \oplus x \oplus x = x$

띠라서, $n$이 주어지면 1부터 $n$까지는 위의 방법으로 얻을 수 있다.

2. $n \lt x \lt 2 ^ a$ 범위의 수 얻기

우리는 여기서 반드시 $n$보다 작거나 같은 수 $2^{a - 1}$를 고를 수 있다. 이 수는 이진수로 나타내면 $10...0$ 꼴로 나타난다.

이제 $a \geq 3$인 상황에서, $n$의 이진수 표현 중 맨 앞의 1을 제외한 뒤의 $a - 1$ 자리를 생각해보자. $a - 1$ 자리의 수는 무조건 $n$보다 작으니 우리는 $n$ 이하의 수 2개를 이용해 얼마든지 $a - 1$ 자리의 어떤 이진수든지 표현할 수 있다. $a - 1$ 자리를 글씨로 쓸 때 어떤 적절한 두 왼쪽과 오른쪽 부분으로 나누어 각각을 표현하는 두 수 $p$와 $q$를 찾아 $p \oplus q$를 구하면 된다.

따라서 다음 공식으로 $n$보다 크면서 $2 ^ a$보다 작은 수를 얻을 수 있다.

> $2^{a - 1} \oplus p \oplus q$

$a = 2 (n = 2, 3)$인 상황에서는 해당하지 않다.

3. 0 얻기

다음이 자명하므로, 0을 얻을 수 있다.

> $1 \oplus 2 \oplus 3 = 0$

하지만 $n$이 2 이하이면 0을 얻지 못한다.

4. 종합

1부터 3까지의 방법에 따라, $a \gt 2$인 상황에서 $$2 ^ a$개의 자연수(0 포함)를 모두 얻을 수 있다.

### 코드

```kotlin
class Solution {
    fun uniqueXorTriplets(nums: IntArray): Int {
        val n = nums.size

        return if (n <= 2) {
            n
        } else {
            n.takeHighestOneBit().shl(1)
        }
    }
}
```

### 복잡도

- 시간복잡도: $O(1)$
- 공간복잡도: $O(n)$
