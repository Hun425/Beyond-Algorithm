## [3345. Smallest Divisible Digit Product I](https://leetcode.com/problems/smallest-divisible-digit-product-i/description/?envType=daily-question&envId=2026-08-06)

### 접근 방법

- Bruteforce 방식

### 코드

```dart
class Solution {
  int smallestNumber(int n, int t) {
    for (int i = n;; i++) {
      if (multipy(i) % t == 0) return i;
    }
  }
    
  int multipy(int n) {
    int result = 1;
    
    while (n > 0) {
      result *= n % 10;
      n ~/= 10;
    }
    
    return result;
  }
}
```

### 복잡도

- 시간복잡도: O(log n)
- 공간복잡도: O(1)

### 회고

- n의 제약사항이 100이아닌 더 큰수였으면 효율적인 방법으로 교체해야함
