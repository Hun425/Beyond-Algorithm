## [3718. Smallest Missing Multiple of K](https://leetcode.com/problems/smallest-missing-multiple-of-k/description/?envType=daily-question&envId=2026-08-25)

### 접근 방법

- 배열의 원소를 `Set`으로 변환해 포함 여부를 O(1)에 확인
- 가장 작은 양의 `k`의 배수인 `k`부터 시작해 `k`씩 증가
- 배열에 존재하지 않는 첫 번째 배수가 정답

### 코드

```dart
class Solution {
  int missingMultiple(List<int> nums, int k) {
    Set<int> numbers = nums.toSet();
    int multiple = k;

    while (numbers.contains(multiple)) {
      multiple += k;
    }

    return multiple;
  }
}
```

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(n)

### 회고

- `k`의 배수만 확인하면 되므로 전체 숫자 범위를 탐색할 필요가 없음
