## [3731. Find Missing Elements](https://leetcode.com/problems/find-missing-elements/description/?envType=daily-question&envId=2026-08-04)

### 접근 방법

- input 배열의 최소, 최대값을 구해서 탐색범위를 잡음
- 최소 ~ 최대의 사이값이 배열에 존재유무를 확인

### 코드

```dart
class Solution {
  List<int> findMissingElements(List<int> nums) {
    Set<int> numbers = nums.toSet();
    int max = nums.first;
    int min = nums.first;

    // 최소, 최대값 산출
    for (int number in numbers) {
      if (min > number) {
        min = number;
      }
      if (max < number) {
        max = number;
      }
    }
    
    List<int> answer = [];
    
    for (int i = min + 1; i < max; i++) {
      if (numbers.contains(i)) continue;
      answer.add(i);
    }
    
    return answer;
  }
}
```

### 복잡도

- 시간복잡도: O(n + {max - min + 1})
- 공간복잡도: O(n)

### 회고

- `contains()`를 사용하는데 `List`는 원소를 순차적으로 탐색하고 `Set`은 `LinkedHashSet`기반이라 해시값 비교를 함
