## [2996. Smallest Missing Integer Greater Than Sequential Prefix Sum](https://leetcode.com/problems/smallest-missing-integer-greater-than-sequential-prefix-sum/description/?envType=daily-question&envId=2026-08-11)

### 접근 방법

- 가장 긴 연속 구간을 찾는게 아니기때문에 인덱스 0부터 탐색 시작한다.
- 연속될 때까지 `prefixSum`을 구하고 `Set`을 사용해서 존재 여부를 확인한다.

### 코드

```dart
class Solution {
  int missingInteger(List<int> nums) {
    int prefixSum = nums[0];

    for (var i = 1; i < nums.length; i++) {
      if (nums[i] != nums[i - 1] + 1) {
        break;
      }

      prefixSum += nums[i];
    }

    final Set<int> numList = nums.toSet();

    while (numList.contains(prefixSum)) {
      prefixSum++;
    }

    return prefixSum;
  }
}
```

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(n)
