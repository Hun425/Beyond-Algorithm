## [3090. Maximum Length Substring With Two Occurrences](https://leetcode.com/problems/maximum-length-substring-with-two-occurrences/description/?envType=daily-question&envId=2026-08-14)

### 접근 방법

- 길이가 유동적인 슬라이딩 윈도우 적용
- 2개의 포인터를 두고 조건에 맞게 옮김
- `right`로 진행하다가 조건에 충족하지 못하면 조건을 충족시킬때까지 `left`를 이동

### 코드

```dart
class Solution {
  int maximumLengthSubstring(String s) {
    int maxLength = 0;
    int left = 0, right = 0;

    final List<int> count = List<int>.filled(26, 0);

    for (right; right < s.length; right++) {
      final int rightIndex = s.codeUnitAt(right) - 'a'.codeUnitAt(0);
      count[rightIndex]++;

      // 3이상일 때 left 이동
      while (count[rightIndex] > 2) {
        final int leftIndex = s.codeUnitAt(left) - 'a'.codeUnitAt(0);
        count[leftIndex]--;
        left++;
      }

      final int currentLength = right - left + 1;
      if (currentLength > maxLength) {
        maxLength = currentLength;
      }
    }

    return maxLength;
  }
}
```

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(1)
