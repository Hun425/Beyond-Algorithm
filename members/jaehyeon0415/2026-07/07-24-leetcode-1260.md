## [1260. Shift 2D Grid](https://leetcode.com/problems/shift-2d-grid/description/?envType=daily-question&envId=2026-07-20)

### 접근 방법

- 2차원 배열을 1차원 배열로 생각함. `(x, y)` 좌표를 1차원 인덱스로 표현하면 `index = x * 열의 개수 + y`
- `k`번 이동한 위치는 `shiftedIndex = (index + k) % 전체 원소 개수`

### 코드

```dart
class Solution {
  List<List<int>> shiftGrid(List<List<int>> grid, int k) {
    final int rowCount = grid.length, columnCount = grid[0].length;
    final int totalElementCount = rowCount * columnCount;
    final int shift = k % totalElementCount;

    // rowCount * columnCount 2차원 배열 생성
    final List<List<int>> shifted = List<List<int>>.generate(
      rowCount,
      (_) => List<int>.filled(columnCount, 0),
    );

    for (int row = 0; row < rowCount; row++) {
      for (int column = 0; column < columnCount; column++) {
        final int index = row * columnCount + column;
        final int shiftedIndex = (index + shift) % totalElementCount;
        final int shiftedRow = shiftedIndex ~/ columnCount;
        final int shiftedColumn = shiftedIndex % columnCount;

        shifted[shiftedRow][shiftedColumn] = grid[row][column];
      }
    }

    return shifted;
  }
}
```

### 복잡도

- 시간복잡도: O(row * column)
- 공간복잡도: O(row * column)

### 회고

- 처음에 2차원 배열을 1차원 배열로 변환해서 shifted 시키고 다시 2차원 배열로 나누는 방법으로 해결
- 이중for문이 별로라 단일반복문으로 변경했으나 모든 원소를 한번씩 방문한다는 사실이 동일하여 원복함
