## [3536. Maximum Product of Two Digits](https://leetcode.com/problems/maximum-product-of-two-digits/description/?envType=daily-question&envId=2026-07-25)

### 접근 방법

- 각 자릿수 순회
- 결국 가장 큰 수와 두번 째로 큰 수를 곱한 값이 제일 큼

### 코드

```dart
class Solution {
  int maxProduct(int n) {
    int max = 0;
    int secondMax = 0;

    while (n > 0) {
      final int digit = n % 10;

      if (digit >= max) {
        secondMax = max;
        max = digit;
      } else if (digit > secondMax) {
        secondMax = digit;
      }

      n ~/= 10;
    }

    return max * secondMax;
  }
}
```

### 복잡도

- 시간복잡도: O(n의 자릿수)
- 공간복잡도: O(1)

### 회고

- 문자열 변환해서 풀지 않으려고 함
