## [3345. Smallest Divisible Digit Product I](https://leetcode.com/problems/smallest-divisible-digit-product-i/)

### 접근 방법

- 문제 그대로 구하기

### 코드

```kotlin
class Solution {
    fun smallestNumber(n: Int, t: Int): Int {

        for (i in n..Int.MAX_VALUE) {
            val product = i.toString().map { it - '0' }.reduce { acc, d -> acc * d }
            if (product % t == 0) {
                return i
            }
        }
        return -1
    }
}
```

### 복잡도

- 시간복잡도: O(1) 
- 공간복잡도: O(1)
