## [1464. Maximum Product of Two Elements in an Array](https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/)

### 접근 방법

- $(nums[i]-1) \times (nums[j]-1)$이 최대가 되려면 그냥 가장 큰 두 값을 고르면 됨 (모든 값이 1 이상이라 -1을 해도 대소 관계가 안 바뀜)
- 원본 배열을 건드리지 않도록 `sorted()`로 정렬 복사본을 만들고 뒤에서 두 개를 사용

### 코드

```kotlin
class Solution {
    fun maxProduct(nums: IntArray): Int {
        val sortArray = nums.toList().sorted()

        return (sortArray[sortArray.size - 1] - 1) * (sortArray[sortArray.size - 2] - 1)
    }
}
```

### 복잡도

- 시간복잡도: O(n log n)
- 공간복잡도: O(n)
