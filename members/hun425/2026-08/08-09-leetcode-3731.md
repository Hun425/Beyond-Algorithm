## [3731. Find Missing Elements](https://leetcode.com/problems/find-missing-elements/)

### 접근 방법

- 문제에서 말하는대로 풀기 

### 코드

```kotlin
class Solution {
    fun findMissingElements(nums: IntArray): List<Int> {
        val sortArray = nums.toList().sorted()

        val min = sortArray[0]
        val max = sortArray.last()

        val answer = mutableListOf<Int>()
        for (i in min+1 until max) {
            if(i !in sortArray) {
                answer += i
            }
        }

        return answer
    }
}
```

### 복잡도

- 시간복잡도: O(n log n)
- 공간복잡도: O(n)

### 회고

- 풀고 보니 min/max만 있으면 되는데 정렬부터 한 건 습관이었던 듯 .... Set으로 바꾸면 탐색도 O(1)이 됨
