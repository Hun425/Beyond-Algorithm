## [3014. Minimum Number of Pushes to Type Word I](https://leetcode.com/problems/minimum-number-of-pushes-to-type-word-i/)

### 접근 방법

- 문제를 잘보면 8로만 나누면 답이 나옴
### 코드

```kotlin
class Solution {
    fun minimumPushes(word: String): Int {
        
        return word.indices.sumOf { it / 8 + 1 }
    }
}
```

### 복잡도

- 시간복잡도: O(n)
- 공간복잡도: O(1)
