## [3536. Maximum Product of Two Digits](https://leetcode.com/problems/maximum-product-of-two-digits/)

### 접근 방법

- n의 자릿수들을 분리한 뒤, 가장 큰 두 자릿수의 곱이 답
- 같은 숫자가 두 번 등장하면 재사용 가능 → 정렬 후 뒤에서 두 개를 집으면 중복 케이스도 자연스럽게 처리됨
- 문자열로 변환해 각 자리를 리스트로 만들고 정렬

### 코드

```kotlin
class Solution {
    fun maxProduct(n: Int): Int {
        //maximum product of two digits
        val digits = n.toString().map { it.toString().toInt() }.toMutableList()

        digits.sort()

        return digits[digits.size - 1] * digits[digits.size - 2]
    }
}
```

### 복잡도

- 시간복잡도: O(d log d) (d = 자릿수, 최대 10)
- 공간복잡도: O(d)

### 회고

- 같은 숫자 재사용 조건을 정렬이 자연스럽게 커버해줘서 분기 없이 풀림
