## 🔀 PR 규칙

1. **브랜치명**: `{github-id}/{일자}-{문제-slug}`
   - 예: `hun425/07-07-two-sum`
2. **PR 제목**: `[YYYY-MM-DD] {문제명} - {github-id}`
3. **PR 본문**: 위 풀이 템플릿 내용 그대로 포함
4. **리뷰 기준**
   - 정답 여부보다 **"다른 풀이 방법이 있는지", "시간/공간복잡도를 더 줄일 수 있는지"** 위주로 코멘트
   - 못 풀었어도 괜찮음 — 시도한 코드와 막힌 지점을 정리해서 PR 올리기
5. **3명 Approve** 받으면 merge
6. 리뷰는 되도록 **24시간 이내** 완료를 목표로 함
7. **수동 머지 금지** (조건을 만족하면 자동 merge 됨, conflict 나면 해결 후 push 하면 됨)

## 태그 규칙

PR을 merge 하기전 태그가 필수로 붙어있어야합니다.

1. 풀이 성공일 경우 SUCCESS
2. 풀이 실패일 경우 FAILED (고민하다 포기한 경우)
3. 계속 도전해 봤는데 도저히 모르겠어서 도움받고 다시 풀어보고 싶은 경우(HELP)

HELP의 경우에는 같은 문제로 다음 주차에 풀이하는 것을 1회 허용합니다. (단, 전주와 비교했을때 풀이의 내용 및 접근 방식이 달라져야합니다.)

풀이 pr 제출 기한은 해당 주의 일요일 23:59분 까지입니다.

상대 pr 리뷰 기한은 다음 주의 화요일 23:59분 까지입니다.

## 유의사항

매주 수요일 자동 리포트가 아래 기준으로 이행 여부를 판정하고 경고를 누적합니다.

- **풀이 이행** (둘 중 하나, 일요일 23:59까지 PR 생성 기준)
  1. 그 주 공통 문제 이슈에 등록된 문제를 푼 경우
  2. 자유 문제를 2개 이상 푼 경우
  - 직전 주 공통 문제를 HELP 라벨로 제출했다면, 이번 주에 같은 문제를 다시 푼 것도 공통 문제 이행으로 인정
- **리뷰 이행**: 그 주에 올라온 다른 멤버의 풀이 PR과 유예 신청 PR 전부에 화요일 23:59까지 리뷰
  - 리뷰가 늦어 머지가 안 된 것은 제출자가 아니라 리뷰를 안 한 사람의 책임
- **경고**: 풀이/리뷰 중 하나라도 미이행이면 그 주 1회 누적 (둘 다 미이행이어도 1회)
- **커피**: 누적 2회가 되면 나머지 인원에게 커피 제공. 리포트 이슈의 커피 체크박스를 체크하면 다음 리포트에서 0회로 초기화
- **유예**: 결혼식, 출장 등 부득이한 사정은 아래 절차로 신청하면 그 기간이 걸친 주의 풀이/리뷰 의무가 면제됩니다.

### 🛌 유예 신청 방법

1. `.github/excuses.json`에 자기 항목을 한 줄 추가합니다. 기간은 하루든 몇 주든 자유롭게 잡을 수 있고, 그 기간과 하루라도 겹치는 주는 모두 유예됩니다.
   ```json
   [
     {"member": "hun425", "from": "2026-09-11", "to": "2026-09-13", "reason": "결혼식"}
   ]
   ```
2. 이 변경으로 PR을 올립니다. 제목 예: `유예 신청: hun425 결혼식 (09-11 ~ 09-13)`, 라벨은 `DOC`
3. 나머지 인원은 이 PR도 **화요일 23:59까지 리뷰해야 합니다** (풀이 PR과 같은 리뷰 의무). approve 하면 자동 머지되고, 동의하지 않으면 PR을 **close** 합니다.
4. 리포트 실행 시점에 머지되었거나 아직 열려 있으면 유예로 인정하고, close된 신청은 인정하지 않습니다. 기간을 늘리려면 `to` 날짜를 고치는 PR을 다시 올립니다.
5. 리포트가 이미 나간 뒤에 올린 신청은 그 주에 소급되지 않습니다.
